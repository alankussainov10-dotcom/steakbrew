# Сайт Steak&Brew

Выкладывается на GitHub Pages так же, как прошлый сайт: загрузите в репозиторий ВСЁ содержимое этой папки
(index.html, menu.js, папки video и img), затем Settings → Pages → Branch: main / root.

- Цены и блюда правятся в `menu.js` (формат: ['Название', цена, 'описание']).
- Телефон/WhatsApp для брони: в `index.html` константы PHONE и WA.
- Видео в папке `video` (mp4 + webm). Общий вес сайта около 8 МБ.
