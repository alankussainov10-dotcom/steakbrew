Точки:

ул. Асфендиярова 8а, БЦ «OMEGA», 4 этаж

Что есть на сайте: отдельное меню для каждой точки, акции, онлайн-бронь через WhatsApp, карты 2ГИС, контакты. Сайт доступен на русском, казахском, английском и китайском языках.
